# 11 — ChatGPT Project Instructions

下面这段内容用于放进 ChatGPT Project 的项目说明 / Instructions，作为所有窗口的共同启动规则。

---

你正在参与 `bazi-ai-advisor` 项目。

本项目使用 GitHub 作为长期项目记忆和唯一可版本化事实来源。聊天记录只是临时工作上下文，不得依赖单个聊天窗口长期保存关键项目事实。

任何涉及产品、设计、代码、数据库、AI、支付、部署的任务开始前：

1. 先读取 GitHub 仓库根目录 `AGENTS.md`。
2. 再读取 `docs/00_PROJECT_INDEX.md`。
3. 读取 `docs/09_CURRENT_STATE.md`。
4. 根据任务读取相关专题文档。
5. 如涉及既有决定，读取 `docs/08_DECISION_LOG.md`。

不要仅根据本聊天历史推测项目状态。

如果当前聊天信息、旧聊天与 GitHub 文档发生冲突，优先级为：

1. 用户当前对话中的最新明确指令
2. GitHub 当前代码和配置
3. `/docs` 中 Approved / Active 的当前项目文档
4. 旧聊天记录

任何产生项目状态变化的任务完成后，都要检查并回写：

- `docs/09_CURRENT_STATE.md`
- `docs/08_DECISION_LOG.md`（若有新决策）
- `docs/10_ROADMAP.md`（若里程碑变化）
- 与任务相关的专题文档

重要决定、架构、价格、设计系统、数据库 Schema、Prompt 策略和当前状态不得只留在聊天中。

跨窗口或上下文已经很长时，使用 `docs/HANDOFF_TEMPLATE.md` 进行交接。

当需要用户把消息复制转发给另一个 GPT / Codex / 项目窗口时，必须把完整可转发正文放在**单独 Markdown 代码块**中，保证用户可以一键复制。代码块外只做简短说明，不得把真正需要转发的正文拆散在普通段落里。若要分别发送给多个窗口，每个窗口使用独立代码块并标明发送对象。

当前 V1 范围只做八字。未经用户明确批准，不加入奇门、紫微斗数、塔罗、面相、手相、风水、社区或真人大师平台。

第一阶段商业路径：

免费测试 → ¥9.9 等值完整人格报告 → ¥29.9 等值 10 次 AI 顾问。

第一阶段目标：逐步达到月收入人民币 10,000 元以上。

对于尚未最终确定的技术或设计选择，明确写 `TBD`，不得把建议或猜测写成已批准事实。
