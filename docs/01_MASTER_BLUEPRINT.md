# 01 — Master Blueprint

## 1. 商业目标

第一阶段唯一商业目标：验证并跑通可持续付费转化。

核心路径：

1. 免费八字测试
2. 低价解锁完整人格报告
3. 购买 AI 顾问次数包
4. 通过体验、复购和后续产品逐步提高用户价值
5. 第一阶段目标：月收入人民币 10,000 元以上

## 2. 目标用户

核心用户：海外华人年轻用户。

产品表达应降低传统“算命摊”距离感，更接近现代人格理解、行为建议与自我探索产品。

## 3. 产品核心价值

八字不是只输出吉凶判断，而应形成：

- 对人格与行为模式的结构化解释
- 优势与风险倾向
- 感情、事业、财务等人生主题的理解
- 大运/流年背景解释
- 现代、可执行的行为建议
- 可继续追问的 AI 顾问体验

## 4. V1 产品边界

V1 只做八字。

明确不做：

- 奇门
- 紫微斗数
- 塔罗
- 面相
- 手相
- 风水
- 社区
- 真人大师平台

任何新增模块必须先验证是否直接帮助商业漏斗，不得因“功能更丰富”而擅自扩张。

## 5. 核心体验原则

- 免费入口足够低摩擦
- 付费价值必须在免费体验之后清楚可见
- 输出避免空泛套话
- 免费与付费内容必须有明显信息增量
- AI 顾问必须能利用用户已有命盘和报告上下文
- 移动端优先保证可用性
- 海外用户需要适应不同币种和支付方式，具体实现以 Business Rules 为准

## 6. 项目长期原则

1. 商业验证优先于大而全。
2. 先跑通漏斗，再扩展命理品类。
3. 代码、产品和 AI Prompt 必须可版本化。
4. 聊天记录不是唯一事实来源。
5. 所有重要变化都进入 GitHub 项目记忆。
