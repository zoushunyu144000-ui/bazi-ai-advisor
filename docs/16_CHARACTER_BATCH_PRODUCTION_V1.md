## 1. 唯一视觉锚点

硬规则：

禁止重新转向日系生活杂志线稿、半写实青年插画、动漫、Q 版、3D 玩具、古风、水墨或精致 AI 立绘。

## 2. 正式资产格式

正式目录：`public/characters/v1/`

命名：

```text
{ten_god}-male.webp
{ten_god}-female.webp
```

建议生产母稿：4:5，1600 × 2000 或更高。  
正式网页导出：约 1200 × 1500 WebP，保留 alpha / 干净背景兼容性，控制文件体积。  
正式 Hero 不烘焙人格标题、说明文字或标签；文字由网页 / Share Card 排版系统负责。

## 3. 统一 Style DNA

- 成人轻卡通，约 4.5–5.2 头身
- 大块图形轮廓，形状先于细节
- 小眼、小嘴、简化鼻子
- 平面低饱和色块
- 阴影最多一层简单块面
- 轻微颗粒，不靠纸纹伪装手绘
- 发丝、布料、皮肤均不做写实细节渲染
- 不做 fashion model pose
- 不做统一漂亮脸
- 角色第一识别来源：**剪影 → 身体向量 → 头型发型 → 比例 → 色块 → 动作 → 五官**

## 5. 人格动作锁定

### 犟种 / 比肩

核心动词：**顶 / 撑 / 扛 / 坚持**。  
主姿势：双脚稳定、身体略向前，不让路但不凶。  
不得画成狠人：犟种的力量方向是“向前顶”，不是“向下压”。

### 撒币 / 劫财

核心动词：**给 / 拉 / 冲 / 加入**。  
主姿势：身体打开，一只手主动伸向别人。  
不得只靠现金、红包、买单表达。

### 享乐主义 / 食神

核心动词：**尝 / 靠 / 闻 / 听 / 享受**。  
主姿势：肩颈放松、身体舒展、手里可以有杯子 / 耳机 / 小食，但不依赖食物。  
视觉基调：**会享受、会生活、有审美、有恢复力**。  
禁止：废宅、瘫、肥胖梗、邋遢、没上进心。

### 天生反骨 / 伤官

核心动词：**问 / 偏 / 拆 / 反**。  
主姿势：明显不对称；身体已经选择一个方向，头部或视线与大流向形成错位。  
推荐：**半转身逆行 / 单腿承重 / 方向冲突**。  
禁止用朋克、黑衣、链条、红黑配色替代“反骨”。

### 抠抠搜搜 / 正财

核心动词：**算 / 收 / 存 / 整理**。  
主姿势：动作幅度小，一只手握手机 / 票据 / 清单，另一只手整理。  
不是穷酸，而是每一份资源都要有去处。

### 搞钱圣体 / 偏财

核心动词：**发现 / 连接 / 交换 / 抓机会**。  
主姿势：身体向前探，目光在场景里扫描，像随时发现连接点。  
禁止西装 + 钱 + 金链的俗套商业符号。

### 老干部 / 正官

核心动词：**正 / 排 / 守 / 检查**。  
主姿势：十人格里最轴对称、最端正。  
幽默来自环境越随意，他越正规。

### 狠人 / 七杀

核心动词：**做 / 扛 / 解决 / 拍板**。  
主姿势：低重心、肩稳定、动作最少。  
禁止黑帮、杀手、军人 cosplay；力量感来自“事情来了我处理”。

### 活菩萨 / 正印

核心动词：**听 / 接 / 扶 / 照顾**。  
主姿势：身体自然朝别人倾斜，手势打开。  
禁止宗教视觉或圣母式夸张光环。

### 道长 / 偏印

核心动词：**看 / 想 / 飘 / 研究**。  
主姿势：人在场，头 / 视线却落在别处；留白最多。  
禁止道袍、符咒、太极、仙侠、玄学 cosplay。

## 6. 男女版本规则

同一人格男 / 女必须共享：

- Body Vector
- Signature Pose 逻辑
- 人格色
- 动作速度
- 轮廓的第一方向
- 场景语法

只允许改变第二层：

- Face Shape
- Hair Shape
- 身体结构
- 服装选择

禁止通过性别改变人格强弱，例如：女版活菩萨更温柔、男版狠人更凶。

## 7. 正式生成模板

每次生产单个角色时，都使用以下任务结构：

```text
REFERENCE
Use docs/assets/character-style-master-v1.webp as the single visual anchor.
Match its flat graphic character language closely.
Do not reinterpret the style.

IDENTITY
{public identity} / {ten_god} / {gender}

BODY VECTOR
{locked body vector}

SIGNATURE POSE
{locked pose description}

FACE / HAIR
{gender-specific secondary layer}

COLOR
Warm ivory + Ink black + personality accent {accent}

RENDER
adult light-cartoon 4.5–5.2 heads, bold flat shapes, simplified facial features,
muted editorial colors, minimal one-layer shadow, subtle grain,
clean brand-character silhouette, no detailed fabric or realistic hair.

OUTPUT
single formal hero character, no baked text, no character sheet layout,
no typography, no watermark, no complex background.
```

## 8. Negative production guardrails

Reject immediately if generation drifts into:

- anime / manga / semi-real anime
- Q 版 / baby proportion / cute mascot
- Japanese lifestyle sketch illustration
- pencil-heavy editorial line art
- watercolor
- glossy 3D / vinyl toy
- fashion model / idol face
- realistic city scene
- perfect AI face / identical face system
- heavy garment rendering
- traditional Chinese costume / xianxia / Taoist props
- generic black-clothes rebel stereotype
- gangster / military 狠人 stereotype

## 9. 生产顺序

### Gate A — 4 Production Pilots

1. `shi_shen-male` — 享乐主义男：测试“松弛但不懒”
2. `shang_guan-female` — 天生反骨女：测试“反骨但不朋克”
3. `qi_sha-male` — 狠人男：测试“强但不黑帮”
4. `pian_yin-female` — 道长女：测试“抽离但不玄学 cosplay”

Gate A 必须同时通过：

- 四张看起来是同一画师 / 同一产品
- 面部语言一致
- 四个剪影明显不同
- 缩小后仍有辨识度
- 没有一张退回旧 AI 立绘或日系线稿风

### Gate B — 完成 10 个 Identity Pair

Pilot 通过后，以“人格 pair”为单位生成男 / 女，而不是先画完 10 男再画 10 女。这样可以优先保证同人格核心一致。

建议顺序：

```text
享乐主义 pair
天生反骨 pair
狠人 pair
道长 pair
犟种 pair
撒币 pair
抠抠搜搜 pair
搞钱圣体 pair
老干部 pair
活菩萨 pair
```

### Gate C — 20 / 20 Integration

20 张正式 WebP 到位后：

- Homepage 10-card
- Birth gender choice
- Result Hero
- secondary personality
- 1080×1350 Share Card
- 1080×1920 Story / XHS
- 390 / 430 / 768 / 1440 viewport

全部 QA 后才解除 Production Visual Gate。

## 10. 最终验收问题

每张角色都必须能回答 YES：

1. 不看名字，轮廓是否像一个独立的人？
2. 和另外 9 个缩成小卡后是否明显不同？
3. 面部 / 上色是否与锁定母版属于同一画风？
4. 人格是否主要靠姿势和身体方向表达，而不是靠道具？
5. 去掉玄学背景后人格是否仍成立？
6. 男 / 女版是否还是同一个人格？
7. 是否避开“漂亮 AI 年轻人换衣服”的统一脸问题？
8. 是否能直接进入 Homepage / Result / Share Card，不需要风格返工？

只有全部通过，才能标记该资产为 **FORMAL V1**。
