# 03 — Design System

状态：Draft / 待视觉窗口继续冻结。

## 1. 品牌方向

产品面向海外华人年轻用户，视觉与文案应强调：

- 现代
- 清晰
- 可信
- 有东方文化来源，但不廉价玄学化
- 适合人格探索与现代行为建议产品
- 商业转化路径明确

## 2. 视觉原则

- Mobile-first，PC 同时保证完整体验
- 信息层级优先于装饰
- 付费区域与免费区域区别清晰但不过度制造焦虑
- 八字元素可以作为文化识别符号，但不应堆砌
- 报告阅读应适合长文本
- AI 顾问应更接近现代咨询/聊天产品，而非“线上算命摊”

## 3. 明确避免

除非未来有新的 Approved 设计决策，否则避免：

- 大红大金传统算命摊视觉
- 龙凤、八卦、符咒等元素无目的堆叠
- 过度神秘、恐惧、灾祸暗示
- 廉价渐变/发光/赛博玄学
- 页面大量动画影响转化和阅读
- 用设计制造虚假的权威感

## 4. 页面体验重点

### 首页
- 5 秒内说明“这是做什么的”
- CTA 清楚
- 免费入口突出

### 出生信息表单
- 降低填写焦虑
- 日期/时间/地点输入友好
- 错误提示具体

### 报告页
- 适合长时间阅读
- 清楚的章节导航
- 免费预览与锁定内容边界自然

### AI 顾问
- 会话界面简洁
- 明确显示剩余次数
- 关键命盘上下文不需要用户重复输入
