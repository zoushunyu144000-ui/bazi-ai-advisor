# 19 — Professional Bazi Report Contract

状态：**PRODUCT CONTRACT / LOCKED 2026-08-22**

## 1. 定位

专业报告不是“人格算法说明书”，也不是命理术语教学。

它的任务只有三件事：

1. 认真、完整地看这张八字；
2. 把传统命理判断翻译成普通人能看懂的白话；
3. 给用户具体、现实、可执行的建议。

一句话：

> **认真看盘，白话讲盘，最后给建议。**

免费人格页负责“我是什么人格”；专业报告负责“我的整张盘怎么看、我在现实生活里该怎么用”。

## 2. 不需要做什么

专业报告不需要长篇解释：

- 为什么系统把你叫作「天生反骨」；
- 为什么不是「搞钱圣体」；
- 为什么某个 Public Personality 排第一；
- 人格标签是如何计算出来的；
- 产品内部如何完成映射。

Public Personality 只是用户进入产品的入口与现代化标签，不应占据专业报告正文。

如需要提及人格标签，只能作为很短的承接，例如：

> 免费结果里的「天生反骨」，放回整张命盘里看，更重要的是你本身表达欲强、对僵化规则敏感，同时盘里现实结果导向也比较明显。

然后立即进入整张命盘分析。

## 3. 报告表达原则

### 3.1 传统判断在内部，白话表达在前台

内部可以使用：

- 月令；
- 十神；
- 透干 / 藏干 / 根气；
- 旺衰；
- 格局；
- 成格 / 破格 / 救应；
- 从格 / 特殊结构；
- 生克制化；
- 冲合刑害；
- 大运 / 流年上下文。

但正文不要堆术语。

优先写：

> 你做事很难只为了“按规定完成”，更在意这件事有没有效率、有没有空间让你自己发挥。

而不是连续写：

> 伤官透干、得根、见财、食伤泄秀……

必要的术语可以放在“命盘依据”折叠区或章节末尾的简短注释中。

### 3.2 先讲这个人，再讲术语

用户阅读顺序应该是：

```text
这对我意味着什么
→ 我平时会怎么表现
→ 哪些地方是优势 / 风险
→ 我现在能怎么做
→ 有兴趣再看命理依据
```

而不是先上一堂八字课。

### 3.3 不做内部推导展示

报告不向用户展示内部评分、算法权重、候选排序、推导链。

用户需要的是结论、解释和建议，不是产品内部计算过程。

## 4. 正式报告章节

专业报告建议锁为 8 个主体章节。

### 01｜先看整张盘

用 2–4 段白话概括整张命盘：

- 整体气质；
- 最明显的结构；
- 盘里最重要的几股力量；
- 最大的优势与矛盾；
- 当前最值得注意的方向。

这部分是整份报告的 Executive Summary。

### 02｜你的性格与做事方式

详细讲：

- 核心性格；
- 思考方式；
- 行动力；
- 表达与沟通；
- 对规则 / 自由 / 安全感 / 竞争的态度；
- 压力下容易出现什么变化。

必须结合整盘，不允许只套某一个十神模板。

### 03｜你的优势，以及最容易吃亏的地方

讲清：

- 天然优势；
- 哪些能力容易做出成绩；
- 哪些优势用过头会变成问题；
- 容易反复踩的坑；
- 什么环境会放大优势，什么环境会消耗本人。

### 04｜工作、学习与事业

重点不是给固定职业清单，而是解释：

- 适合怎样的工作方式；
- 适合稳定系统还是高自主环境；
- 更适合做执行、管理、专业、创作、商业、资源整合中的哪类角色；
- 学习方式；
- 与上级 / 合作伙伴相处；
- 职业选择时应该优先看什么。

最后给具体建议。

### 05｜钱、资源与现实选择

讲：

- 对钱与安全感的态度；
- 获取资源的方式；
- 守成 / 冒险倾向；
- 决策中容易出现的财务性格；
- 适合怎样管理收入、消费、风险与长期规划。

不得把八字当作投资建议。

### 06｜感情、人际与边界

讲：

- 亲密关系里的表达方式；
- 需要怎样的相处空间；
- 容易被什么类型吸引；
- 常见冲突来源；
- 容易迁就、控制、回避还是直接对抗；
- 怎样建立更舒服的边界与沟通方式。

不编造童年经历，不断言婚姻结局。

### 07｜你现在所处的阶段

在大运 / 流年能力进入产品后，这一章结合真实岁运上下文讲：

- 当前阶段主题；
- 哪些事情更容易被放大；
- 哪些方面适合推进；
- 哪些方面适合稳一点；
- 未来一段时间值得观察什么。

没有可靠岁运数据时不得伪造。

### 08｜给你的现实建议

必须具体、可执行。

建议优先覆盖：

- 工作 / 学习；
- 金钱；
- 关系；
- 压力管理；
- 重大选择时的决策原则；
- 未来 3–6 个月可以开始做的事情。

避免空泛的“相信自己”“保持平衡”。

## 5. 专业依据如何展示

专业性不能靠术语堆砌，而要靠“报告确实建立在这张盘上”。

建议页面底部保留：

### 命盘依据 / 专业模式

用户主动展开后再看：

- 四柱；
- 日主；
- 月令；
- 主要十神；
- 透藏根气；
- 旺衰 / 格局结论；
- 关键组合关系；
- 大运信息；
- 采用的 Rule Profile / School；
- 存在争议时的说明。

这是“证据区”，不是报告正文主体验。

## 6. AI 职责

正确链路：

```text
Deterministic Bazi facts
→ Traditional Pattern / Structure Result
→ Evidence packet
→ LLM 用白话组织分析与建议
→ Structured validation
→ Professional Report
```

AI 可以：

- 组织内容；
- 用白话解释；
- 综合多个已确认结构；
- 给现实建议。

AI 不可以：

- 重新排盘；
- 自己取格；
- 修改传统结构结论；
- 为了文案顺畅发明命理事实；
- 展示隐藏推理链。

## 7. 与既有 AI 分支的关系

仓库已有 `feature/ai-system-v1`，其中已经实现过：

- ContextAssembler；
- Provider Boundary；
- Report Runtime；
- versioned prompt；
- structured JSON Schema；
- evidence key validation；
- Advisor Runtime。

这些技术架构继续保留并复用。

其中旧 `ai-report/full-personality/1.0.0` 的 8 节人格报告结构属于历史产品版本，**不是当前最终专业报告内容契约**。

未来恢复 AI Report implementation 时：

- 不从零重写技术架构；
- 更新 Report Prompt / Schema 到本文件定义的专业八字报告；
- 保留 evidence-first、structured output、validation 等已有正确工程设计。

## 8. Free vs Paid

免费层：

- 主人格体验完整；
- 年轻化；
- 易传播；
- 轻量展示命盘依据。

专业付费报告：

- 不重复免费人格页；
- 真正展开整张八字；
- 白话讲清多个生活领域；
- 给更完整、具体的现实建议；
- 可查看专业依据。

付费价值来自：

> **更完整地看懂自己的盘，并知道现实中怎么用。**

而不是：

> **花钱看系统为什么给你这个人格标签。**
