# 17 — Product Design Report V1

状态：**APPROVED PRODUCT DESIGN / 2026-08-22 / Traditional Translation Revision**  
项目：**八字人格 / Bazi Personality**

> 若与 `docs/13_PERSONALITY_IP_BIBLE.md` 或 `docs/18_TRADITIONAL_BAZI_TRANSLATION_CONTRACT.md` 冲突，以前两者为准。

## 1. 产品总定义

这不是重新发明一套人格学，而是：

> **把传统八字命理判断翻译成现代年轻人能理解、愿意分享的人格语言。**

产品原则：

```text
传统命理负责判断
现代产品负责翻译
AI 只负责表达
```

品牌语气：

> **里面认真算，外面认真发疯。**

## 2. 完整产品三层

### 第一层：Traditional Bazi Facts / Structure

负责真实命理结构：

- 四柱；
- 月令；
- 十神；
- 透干 / 藏干 / 根气；
- 旺衰；
- 格局候选；
- 成格 / 败格 / 破格 / 救应；
- 从格 / 特殊格局；
- 组合关系；
- 流派分歧与不确定性。

所有判断必须来自明确、可追溯、版本化的传统规则。

### 第二层：Modern Personality Translation

把上述传统结构翻译成人格语言：

- 主人格；
- 次级倾向；
- 主导 / 明显 / 辅助；
- 场景化现代解释。

这一层不重新取格，不反向修改传统结论。

### 第三层：Brand / Growth / Commercial

- 10 个固定 Character IP；
- Personality Dossier；
- Share Card；
- 付费专业报告；
- 后续 AI Advisor。

## 3. 10 个固定官方 IP

**10 Public Personality = 10 固定官方 Character IP。**

| Traditional archetype | Public Personality | Character |
| --- | --- | --- |
| 比肩 | 犟种 | 固定女角色 |
| 劫财 | 撒币 | 固定男角色 |
| 食神 | 享乐主义 | 固定男角色 |
| 伤官 | 天生反骨 | 固定女角色 |
| 正财 | 抠抠搜搜 | 固定女角色 |
| 偏财 | 搞钱圣体 | 固定男角色 |
| 正官 | 老干部 | 固定女角色 |
| 七杀 | 狠人 | 固定男角色 |
| 正印 | 活菩萨 | 固定男角色 |
| 偏印 | 道长 | 固定女角色 |

Character 代表人格，不代表用户本人。用户性别不改变 Character。

## 4. Public Personality 不是 Traditional Pattern 的同义词

必须明确：

```text
Traditional Pattern = 命理结构分类
Public Personality = 对命理结构的现代人格翻译
```

例如：

- 一个用户可能传统判断为伤官格，并见明显财星、形成伤官生财；
- 公网主标签可以是「天生反骨」；
- 明显副倾向可以是「搞钱圣体」；
- 专业报告解释为什么这个传统组合产生这种现代人格表达。

不允许因为财星数量更高，就直接覆盖传统伤官格判断。

## 5. 不成格 / 兼格 / 从格如何处理

人格系统不能要求每个八字都是纯型。

传统层必须允许：

- 成格清晰；
- 兼格；
- 格局不纯；
- 破格；
- 有救应；
- 从格；
- 假从；
- 不成单一格；
- 流派判断存在分歧。

公网可现代化表达成：

```text
主人格：天生反骨
明显副倾向：搞钱圣体
结构状态：混合度较高
```

但不能为了产品整齐而伪造成纯伤官 / 纯偏财。

## 6. 关于“人格比例”

此前设计的：

```text
天生反骨 41%
搞钱圣体 26%
狠人 14%
```

**暂不作为正式产品输出。**

原因：如果百分比由我们自行把十神数量、行为维度、family score 等加权而来，本质上仍然是在创造新的命理算法。

当前免费层应优先使用传统语义更诚实的强弱表达：

```text
主导：天生反骨
明显：搞钱圣体
辅助：狠人
```

未来只有在找到传统依据充分、可复算、经过命例验证的量化规则后，才允许恢复精确比例。

## 7. 免费传播层

免费结果必须完整，不做残缺诱导付费。

建议结构：

1. 主人格大名；
2. 固定 Character；
3. 锚点句；
4. Tags；
5. 主导 / 明显副倾向 / 辅助结构摘要；
6. 朋友眼里的你；
7. A 面；
8. 翻车面；
9. 工作 / 学习 / 关系 / 冲突 / 压力 / 恢复 / 决策 / 金钱；
10. 成长建议；
11. 为什么得到这个人格；
12. 专业八字依据折叠区；
13. Share Card。

免费层重点完整解析主人格；副倾向轻量提示即可。

## 8. 分享传播设计

传播继续遵循：

- 社交货币：人格名值得说出口；
- 情绪：好笑、被说中、反差；
- 公开性：固定角色和人格名高识别；
- 触发：工作、恋爱、花钱、压力、朋友；
- 实用价值：免费结果本身有理解价值；
- 故事：主人格 + 副倾向 + 翻车面形成个人故事。

分享卡可展示：

```text
我是：天生反骨
明显副倾向：搞钱圣体
```

暂不展示没有传统依据的精确人格百分比。

## 9. 付费专业报告

专业报告的核心不是“更长”，而是“更传统、更有依据、更能解释个体差异”。

### A. Traditional Bazi Report

至少解释：

- 采用的传统规则体系；
- 月令；
- 十神；
- 透藏根气；
- 旺衰；
- 格局判断；
- 成败 / 破格 / 救应；
- 从格 / 特殊结构；
- 重要组合；
- 为什么不是其他格；
- 流派争议 / 不确定性。

### B. Modern Personality Translation

解释：

- 为什么主标签是这个人格；
- 为什么出现副倾向；
- 同样是「天生反骨」，为什么这个人更偏赚钱、另一个人更偏表达；
- 工作、关系、金钱、压力中的具体体现。

付费卖的是：

> **对传统命盘结构的深入解释 + 现代语言翻译。**

## 10. AI 边界

正确架构：

```text
Traditional deterministic facts
→ TraditionalPatternResult + Evidence
→ translation rules
→ typed evidence packet
→ LLM narrative
→ structured validation
→ report
```

LLM 不得：

- 重新排八字；
- 自己取格；
- 发明百分比；
- 覆盖 deterministic 结论。

## 11. 当前必须先做的工程工作

下一步不是继续调人格百分比，而是：

### Traditional Bazi Rule Audit

逐条审计：

- 哪些规则是传统核心；
- 哪些是流派选择；
- 哪些只是程序实现细节；
- 哪些是我们自己加的实验权重。

然后正式建立：

```text
TraditionalPatternResult
+ Evidence
+ School / Rule Profile
+ Confidence / Ambiguity
```

完成之后再接现代人格翻译。

## 12. 一句话产品模型

> **我们不是用八字素材发明一个人格测试；我们是在保留传统命理判断的前提下，把它翻译成一个现代、年轻、能传播的产品。**
