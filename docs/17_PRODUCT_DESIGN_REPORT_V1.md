# 17 — Product Design Report V1

状态：**APPROVED PRODUCT DESIGN / 2026-08-22**  
项目：**八字人格 / Bazi Personality**  
适用：V1 完整公网体验 + Post-V1 付费产品架构

> 本报告用于解释完整产品怎么成立。若与 `docs/13_PERSONALITY_IP_BIBLE.md` 冲突，以 Personality IP Bible 为最高 Source of Truth。

## 1. 产品总定义

产品不是传统算命站，也不是把十神换成十个网络梗。

完整产品由三层组成：

```text
真实八字事实层
→ 人格解释层
→ 传播 / 商业产品层
```

核心原则：

> **里面认真算，外面认真发疯。**

免费层负责“我是谁、我的人格配方是什么、为什么有点像、我愿不愿意分享”；付费层负责“这些配方为什么这样组合、为什么我和同一主人格的人仍然不同、真实命盘结构怎样影响我”。

## 2. Character IP 架构 — 10 个固定官方 IP

### 2.1 核心决策

**10 个 Public Personality = 10 个固定官方 Character IP。**

不再生产“每个人格男版 + 女版”双角色系统。

角色代表的是人格本身，不代表用户本人。用户性别不得改变 Character identity。

例如：

```text
任何用户测出 shang_guan
→ 都看到同一个「天生反骨」官方角色
```

出生性别若 deterministic Bazi Engine 仍需要，可继续作为排盘输入；它不得承担“选择男角色 / 女角色”的视觉功能。

| Machine key | Public Personality | Canonical Character |
| --- | --- | --- |
| `bi_jian` | 犟种 | 固定女性角色 |
| `jie_cai` | 撒币 | 固定男性角色 |
| `shi_shen` | 享乐主义 | 固定男性角色 |
| `shang_guan` | 天生反骨 | 固定女性角色 |
| `zheng_cai` | 抠抠搜搜 | 固定女性角色 |
| `pian_cai` | 搞钱圣体 | 固定男性角色 |
| `zheng_guan` | 老干部 | 固定女性角色 |

整体保持 5 男 + 5 女，但性别只属于 Character 设定，不属于用户映射规则。

### 2.3 为什么这样做

固定角色带来四个产品价值：

1. **识别度**：看见角色就知道人格，不需要记 20 张脸。
2. **IP 资产积累**：一个人格长期由同一角色承载，能发展表情、动作、场景与故事。
3. **传播效率**：分享卡、小红书、首页、人格图鉴统一使用同一视觉记忆点。
4. **生产集中**：把精力从“多画一倍”转为“把 10 个角色真正做成品牌资产”。

### 2.4 Character Master 与延展

V1 每个人格只需要 1 个正式 Character Master，共 10 张。

后续扩展不是“男女版”，而是同一角色的状态 / 场景 Variant：

```text
Character Master
├── Homepage Hero / Card crop
├── Result Hero
├── Share Card
├── Avatar
├── 表情 / reaction
├── 工作状态
├── 恋爱状态
├── 压力状态
└── 社交内容插图
```

## 3. 免费人格产品 — Public Personality + Personality Mix

免费产品不是付费版残缺预览，必须本身完整、爽、可分享。

用户完成出生信息后，deterministic chain 输出：

```text
Birth normalization
→ Bazi Engine
→ Interpretation personality-map/0.2.0
→ personality factor weights
→ dominant personality
→ secondary personality
→ 15 personality dimensions
```

### 3.1 免费必须展示“人格因子配比”

免费结果不仅告诉用户一个主人格，还要把经过确定性规则计算出的 **10 个 Public Personality 因子比例**展示出来。

示意：

```text
你的八字人格配方

天生反骨   41%   ← 主人格
搞钱圣体   26%
狠人       14%
犟种        8%
道长        5%
其他人格    6%
```

正式产品可选择：

- 默认展示 Top 4–5 + “展开全部”；或
- 直接展示完整 10 因子。

但必须让用户明确知道：**自己不是被粗暴塞进一个标签，而是有一组真实的混合人格权重。**

### 3.2 免费解析边界

免费层的“数值透明”与“深度解析”必须分开：

**免费给用户看比例，但只对主人格做完整详细解析。**

其他因子免费只提供：

- Public Personality 名称
- 对应百分比 / 权重
- 主 / 次级标记
- 最多一句极短提示（可选）

免费不展开其他因子的：

- 深层成因
- 与主人格的组合关系
- 内在矛盾来源
- 八字结构为什么形成这个比例
- 工作 / 金钱 / 感情中的组合效应
- 结构清晰度 / 混合度的专业解释

这些属于付费人格光谱解析。

### 3.3 免费主人格完整 Dossier

免费主人格至少包含：

- 唯一主人格
- 固定官方 Character
- 锚点句 / 一句话毒舌
- 6 Tags
- 朋友眼里的你
- A 面 / 翻车面
- 第二人格名称与比例
- 10 因子人格配比
- Personality Dimensions
- 工作 / 学习 / 关系 / 冲突 / 压力 / 恢复 / 决策 / 金钱
- 成长建议
- 为什么会得到这个主人格
- 专业八字依据折叠区
- Share Card

免费层回答：

> **“我主要是什么人，以及我的人格配方大概长什么样？”**

### 3.4 百分比真实性约束

任何百分比都必须：

- 来自 deterministic engine / versioned normalization rules；
- 使用稳定、可复算的算法；
- 同一命盘重复计算结果一致；
- 清楚区分“人格因子权重”与传统命理中的绝对事实；
- 不允许 LLM 自行编造或为了好看调整数字。

如果当前 `personality-map/0.2.0` 尚不能直接产出可解释、归一化到 100% 的 10 因子权重，则 V1 实现前必须补一个明确版本化的 normalization contract，不能用前端随机比例代替。

## 4. 传播设计 — 《疯传》原则落地

传播不是功能附加，而是产品结构的一部分。

### Social Currency / 社交货币

人格名与人格配方都必须让用户愿意说：

- “我是搞钱圣体。”
- “我居然 41% 天生反骨 + 26% 搞钱圣体。”
- “你也是天生反骨，为什么我们的配比完全不一样？”

### Emotion / 情绪

结果需要制造：好笑、被说中、反差、想吐槽朋友的情绪，不做平淡心理测评腔。

### Public / 公开性

每个固定角色、人格名、配色、Share Card 与人格配方摘要都必须具备辨识度。

### Triggers / 触发

工作、恋爱、花钱、冲突、压力、社交等日常场景持续让用户想起人格标签。

### Practical Value / 实用价值

免费结果必须真正提供可用的自我理解，而不是只有梗；公开人格配比会进一步提升“这不是单一标签”的可信度。

### Stories / 故事

通过“朋友眼中的你 / 真正的你 / 翻车时的你 / 第二人格 / 我的混合配方”形成可讲述的个人故事。

## 5. 付费产品 — Bazi Personality Spectrum

### 5.1 核心定义

付费层不再卖“看见比例”的资格，也不是给主人格多写几千字。

**比例免费可见，付费卖的是比例背后的解释。**

它回答：

> **“为什么这些人格力量会以这个比例出现在我身上？它们如何互相作用？为什么我和另一个同主人格的人仍然不同？”**

产品名建议：

**八字人格光谱 / Bazi Personality Spectrum**

### 5.2 1 + 2 + N 架构

```text
1 个主人格
+ 1–2 个显著副人格 / 次级动力
+ N 个八字结构修正因子
```

修正因子可来自后续经过验证的 deterministic facts，例如：

- 十神分布与相对权重
- 日主状态 / 身强弱
- 五行结构与偏向
- 格局清晰度 / 混合度
- 关键组合关系
- 冲合刑害
- 寒暖燥湿等经过明确规则定义的结构因素

任何比例、权重、结构标签必须来自 deterministic engine 或明确版本化规则，LLM 不得自行编造数字。

### 5.3 人格纯度 / 结构清晰度

不要强迫所有人都成为“纯型”。

报告可以明确区分：

- 高集中：主人格非常突出
- 中等混合：主人格 + 明显副型
- 高混合：多股动力接近

免费可以显示“你的配比”；付费才详细解释“为什么会形成这样的集中 / 混合结构，以及它如何影响现实行为”。

### 5.4 付费报告内容

完整付费报告建议包含：

1. 人格 DNA：主型 / 副型 / 隐藏倾向的详细解释
2. 免费已展示的人格配比的深度解读
3. 结构清晰度 / 混合度
4. 主人格 × 副人格的组合机制
5. 核心内在矛盾
6. 优势与代价
7. 工作与职业动力
8. 金钱与资源模式
9. 关系与亲密模式
10. 冲突与边界
11. 压力 / 防御 / 恢复
12. 决策方式
13. 成长建议
14. 真实八字结构解释
15. 专业命理依据附录
16. 未来可扩展的运势上下文（不进入当前 V1 release）

付费层回答：

> **“为什么我的人格配方会是这样，以及这些力量放在一起意味着什么？”**

## 6. 免费 → 付费转化逻辑

不能用“不给你看其他人格比例”制造信息黑箱。

正确路径：

```text
免费主人格完整解析
+
免费显示真实人格因子配比
↓
用户发现自己并非纯型
↓
产生问题：
“为什么我 41% 天生反骨，却还有 26% 搞钱圣体？”
↓
付费解锁这些比例之间的组合关系、成因和现实表现
↓
完整「八字人格光谱解析」
```

建议 CTA：

> **你已经看见自己的配方。现在看看，为什么你会是这个组合。**

或：

> **41% 天生反骨 + 26% 搞钱圣体，会把你变成怎样的人？**

支付未上线前只能显示“即将开放”，不得伪造购买流程。

## 7. Share Card 传播内容

主分享卡仍以主人格与固定 Character 为视觉中心，不把十个比例全部塞满画面。

建议 Share Card 增加一个轻量“人格配方摘要”：

```text
天生反骨 41%
搞钱圣体 26%
狠人 14%
```

即 Top 3 因子即可。

这样既保持视觉冲击，又让不同的“天生反骨”分享卡具有个体差异，强化朋友之间比较和二次测试。

## 8. AI 与专业性的边界

正确架构：

```text
Deterministic Bazi facts
→ versioned personality weighting / normalization rules
→ typed evidence packet
→ LLM narrative generation
→ structured validation
→ report
```

LLM 只负责解释与表达，不重新排盘、不猜格局、不随机造百分比、不覆盖 engine facts。

专业感来自“可追溯依据 + 个体差异”，而不是传统术语堆叠。

## 9. 完整产品终局

```text
免费传播入口
10 固定 Public Personality IP
↓
主人格完整 Dossier
+
免费人格因子配比
↓
Share Card / 好友回流
↓
八字人格光谱深度解析（轻付费）
↓
更深层个体报告
↓
AI Advisor / 后续顾问能力
```

10 个 IP 是品牌层；免费配比是个性化展示层；人格光谱解析是付费解释层；八字事实是专业底座；AI 是叙事解释层。

## 10. V1 完整发布边界

“V1 不做所有未来功能”不等于“V1 做残缺版”。

V1 必须完整交付：

- 10 / 10 固定官方 Character Master
- 完整 Homepage
- 完整 Birth UX
- deterministic Bazi → Interpretation
- 10 / 10 Public Personality
- **可复算的 10 因子人格比例 / Personality Mix**
- 主人格完整 Dossier
- 其他因子比例可见但不做深度解析
- 完整分享卡，建议包含 Top 3 配比摘要
- 手机端完整 QA
- 所有正式资产真实接入
- 无 placeholder / 临时人物 / 性别双资产残留依赖

V1 可以暂不实现 payment / AI Advisor / 付费人格光谱解析，但免费人格配比本身属于 V1 完整体验，不应延后。

## 11. 一句话产品模型

> **10 个固定角色负责让人记住我们；免费主人格负责让人觉得“这就是我”；免费人格配比让人发现“原来我不只是一种人格”；付费八字人格光谱负责解释“为什么我是这个组合”；专业八字事实负责建立可信度；分享卡负责把下一个人带进来。**
