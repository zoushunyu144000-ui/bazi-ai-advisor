# V1 八字抽象人格 IP 圣经

状态：Presentation / Product V1 角色设定基线  
适用范围：结果页、分享卡、角色插画、年轻化人格文案  
定位：八字版 SBTI；轻娱乐人格测试 + 轻付费深度人格分析与成长建议

> 核心原则：里面认真算，外面认真发疯。

## 1. 产品定位

V1 不追求把网站做成复杂、严肃、学术化的传统八字平台。

核心用户体验是：

```text
出生信息
↓
稳定排盘 / 人格映射
↓
抽象人格 IP
↓
免费结果页
↓
可截图分享
↓
轻付费深度人格报告 / 成长建议
```

免费层首先追求：

- 好玩
- 一眼能懂
- 有一点损
- 有生活感
- 愿意截图分享
- 让用户产生“怎么这么像我”的反应

深度付费层再负责补充：

- 更完整的人格解释
- 工作 / 学习模式
- 关系模式
- 压力状态
- 容易踩的坑
- 成长建议
- 第二驱动力 / Flow

传统八字术语主要留在后台，不要求普通用户理解。

## 2. 与 Machine Contract 的边界

本文件是**展示层 / 产品层人格 IP 基线**，不是新的 deterministic interpretation contract。

`modules/interpretation/PERSONALITY_ARCHETYPE_SPEC.md` 仍然负责 machine-layer 输出与版本化规则。

本文件只负责：

```text
machine result / approved mapping
↓
public personality name
↓
character IP
↓
copy / pose / props / share card
```

不得因为本文件的 meme 名称而反向修改八字事实、十神分数、人格维度或 deterministic engine。

特别说明：

- 当前 machine taxonomy `personality-map/0.2.0` 仍以十神候选为稳定机器层。
- 本文件中的“建禄 / 月劫”属于产品目标人格骨架表达；在正式工程绑定前，需要经过 approved mapping / traditional host 规则确认。
- 不得仅凭本文件假装当前 production engine 已经完成传统格局判定。

## 4. 总体角色设计原则

这不是：

- MBTI 企业吉祥物
- 传统国风职业人物
- 古装八字角色
- Q 版儿童卡通
- AI 精致二次元帅哥美女合集

我们需要的是：

> 十个现实生活中真的可能认识的怪人。

角色重点不是“漂亮”，而是：

- 有性格
- 有毛病
- 有动作
- 有生活感
- 有一点欠
- 有一点荒谬
- 单独看人物也能大概猜到他是什么怪人

每个人物都应该是在**犯自己的性格毛病**，而不是站着摆 pose。

## 5. 年龄、性别与视觉绑定

所有角色视觉年龄：**18–28 岁**。

必须年轻，不要做成：

- 大叔 / 大姐
- 中年干部
- 老道人
- 老和尚
- 企业高管

每个人格最终需要：

- 男版
- 女版

男女版必须是**同一种人格**。

性别只影响：

- 发型
- 穿搭
- 脸型
- 部分生活道具

不得改变人格逻辑。

结果页只展示与用户选择 / 资料匹配的单一性别角色，不同时展示男女两个版本。

## 6. 十大人格角色设定

### 6.1 建禄｜犟种

核心：

非常自我驱动。能自己干的事情就不愿意求人。自尊心强，不爱示弱。困难来了第一反应是：

> “我自己来。”

A 面：

- 独立
- 自驱
- 有主见
- 能扛事
- 自己给自己兜底

玩脱以后：

- 死犟
- 不会求助
- 明明搞不定还硬撑
- 别人越劝越来劲

经典台词：

> “不用，我自己来。”

朋友吐槽：

> “这人不到走投无路是不会开口求人的。”

视觉场景：

一个人抱很多东西，别人伸手想帮，他明显快拿不住了，还用手肘挡一下。

代表物：

- 纸箱
- 工具
- 胶带
- 电脑
- 背包
- 说明书

不要画成：冷酷霸总、孤独杀手、肌肉硬汉。

---

### 6.2 月劫 / 劫财｜撒币

核心：

仗义、爱参与。有人、有局、有竞争的地方就容易出现。朋友需要帮忙、有人买单、有人比赛，第一反应都可能是：

> “我来。”

A 面：

- 仗义
- 敢争
- 行动快
- 社交有能量
- 容易把大家聚起来

玩脱以后：

- 钱留不住
- 人来疯
- 争强好胜
- 朋友太多
- 哪哪都有他

经典台词：

> “算了算了，我来。”

朋友吐槽：

> “钱没多少，朋友是真多。”

视觉场景：

一只手搂朋友，一只手扫码付款；或者大家还没决定参加，他已经报名了。

代表物：

- 手机付款码
- 红包
- 账单
- 聚会桌
- 咖啡
- 一堆群聊通知

不要画成：败家子、土豪、纯粹撒钱。

---

### 6.3 食神｜好吃懒做

核心：

人生首先得舒服一点。喜欢吃、聊、玩、表达、享受、松弛和有趣，不喜欢长期苦哈哈硬卷。

不是没能力，而是：

> “能不能别这么累？”

A 面：

- 松弛
- 会享受生活
- 表达力强
- 创意多
- 好相处
- 能带来快乐

玩脱以后：

- 拖延
- 怕累
- 沉迷舒服区
- 重要事情也想等等再说

经典台词：

> “急啥，再玩会儿。”

朋友吐槽：

> “正事可以晚点，饭点绝不能错过。”

视觉场景：

考试明天开始，他窝在沙发上打游戏，旁边全是零食；或者别人工作到崩溃，他先研究晚上吃什么。

代表物：

- 零食
- 游戏机
- 奶茶
- 耳机
- 沙发
- 外卖

不要把“好吃懒做”画成胖子或做身材羞辱。这是行为状态，不是体型。

---

### 6.4 伤官｜天生反骨

核心：

别人看到规则说“好的”，他看到规则先问：

> “凭什么？”

喜欢质疑传统方法、权威、固定流程和别人默认正确的事情。如果发现一个方法很蠢，可能直接重做。

A 面：

- 创新
- 独立判断
- 敢表达
- 重构能力
- 不盲从

玩脱以后：

- 嘴硬
- 爱顶
- 容易让人觉得难搞
- 有时为了反对而反对

经典台词：

> “凭什么？”

朋友吐槽：

> “你最好别问他意见，他真会说。”

视觉场景：

别人认真听课，他在试卷边上写“这题有问题吧？”；或者会议里所有人点头，只有他举手。

代表物：

- 满是红字的纸
- 问号
- 贴纸
- 涂鸦
- 电脑
- 改得面目全非的方案

动作：歪坐、挑眉、托腮、举手质疑。

不要画成纯杠精、愤怒青年或模板朋克。

---

### 6.5 正财｜抠抠搜搜

核心：

钱不是不能花，但是：

> “你得让我觉得值。”

自然会考虑价格、用途、浪费、长期使用和投入产出。不是单纯没钱，而是对“不值”非常敏感。

A 面：

- 务实
- 稳定
- 会过日子
- 资源利用率高
- 生活能力强

玩脱以后：

- 算太细
- 怕浪费
- 有时舍不得
- 花一点钱都想研究半天

经典台词：

> “这真的值吗？”

朋友吐槽：

> “买杯奶茶都能研究半小时优惠券。”

视觉场景：

手机同时打开比价、优惠券、计算器和评价，在研究“买大杯是不是更划算”。

代表物：

- 优惠券
- 会员卡
- 计算器
- 购物袋
- 价格标签
- 积分

不要画成穷、寒酸、守财奴、铁算盘。

---

### 6.6 偏财｜搞钱圣体

核心：

看到任何东西，脑子都会自动扫描：

> “这个能不能赚钱？”

喜欢机会、资源、认识人、项目、副业和新玩法。本人不一定已经很有钱，但赚钱点子非常多。

A 面：

- 机会敏感
- 商业直觉
- 路子多
- 会连接资源
- 反应快

玩脱以后：

- 项目太多
- 追热点
- 容易三分钟热度
- 什么都想插一脚

经典台词：

> “等等，这能不能赚钱？”

朋友吐槽：

> “本人钱不一定多，项目一天能想八个。”

视觉场景：

咖啡店里别人聊天，他突然在纸巾上开始画商业模式、价格、用户和利润；或者手机开十个聊天窗口。

代表物：

- 手机
- 二维码
- 咖啡
- 便签
- 项目草图
- 群聊
- 银行卡

不要画成富豪、华尔街精英、金融男或满身人民币。

---

### 6.7 正官｜老干部

核心：

明明二十几岁，却总有一种：

> “大家还是正规一点吧。”

讲规则、责任、场合、分寸、体面和秩序。别人觉得“差不多得了”，他觉得“不太合适吧”。

A 面：

- 靠谱
- 责任感强
- 守规则
- 有分寸
- 关键事情不乱来

玩脱以后：

- 太正经
- 容易端着
- 什么都想规范
- 容易扫兴
- 容易管太多

经典台词：

> “咱们还是正规一点。”

朋友吐槽：

> “出来玩都能被他开成工作会议。”

视觉场景：

大家出去旅游，所有人在拍照、吃东西；老干部在看时间、数人数、确认路线、提醒“还有五分钟集合”。

代表物：

- 保温杯
- 手表
- 日程表
- 文件夹
- 手机备忘录
- 行程表

服装必须仍是年轻人的衣服，可以干净、整齐、稍微过分规矩，但不要真的画成中年领导、官员、干部制服或班主任。

---

### 6.8 七杀｜狠人

核心：

平时不一定最吵，但真遇到难事、压力、竞争和风险，他是真的敢上。别人还在讨论，他已经开始干。

A 面：

- 抗压
- 果断
- 敢承担
- 有行动力
- 硬局能顶

玩脱以后：

- 对自己太狠
- 容易过度用力
- 什么事情都当成战斗
- 不会停

经典台词：

> “我来。”

朋友吐槽：

> “这人对别人狠，对自己更狠。”

视觉场景：

大家看到很难的事情开始犹豫，他已经卷袖子、拎包、站起来：“走。”

代表物：

- 运动包
- 钥匙
- 手机
- 绷带
- 水
- 装备

表情不是生气，而是冷静、集中、准备干活。

不要画成暴力狂、黑社会、肌肉男或凶狠大哥。“狠”主要是对困难敢上。

---

### 6.9 正印｜活菩萨

核心：

自己已经很忙，但看到别人有麻烦还是会：

> “算了，我帮你吧。”

喜欢照顾、理解、接住别人、提供信息和解决问题，也比较愿意学习和吸收。

A 面：

- 包容
- 有耐心
- 理解能力强
- 愿意帮助
- 容易让别人觉得安心

玩脱以后：

- 替别人操心
- 帮太多
- 容易吃亏
- 自己行动反而慢
- 边界容易模糊

经典台词：

> “算了，我帮你吧。”

朋友吐槽：

> “又开始普度众生了。”

视觉场景：

自己手里已经拿了一堆东西，还在给别人递充电宝、纸巾、水、药、资料，结果自己的手机掉地上。

代表物：

- 充电宝
- 纸巾
- 药
- 书
- 水
- 各种别人需要的小东西

不要画成佛像、和尚或宗教菩萨。“活菩萨”只是互联网外号。

---

### 6.10 偏印｜道长

核心：

大家最近研究工资、恋爱、旅游和吃什么；他最近在研究命理、荣格、意识、宗教、冷门哲学、AI、奇怪网站和没人关心的理论。

有一种跟现实世界连接不是特别稳定的感觉。

A 面：

- 冷门洞察
- 精神世界丰富
- 非标准思维
- 容易研究别人忽略的东西

玩脱以后：

- 越研究越远
- 疏离
- 闭关
- 失联
- 脑回路越来越难懂

经典台词：

> “说了你也不感兴趣。”

朋友吐槽：

> “最近又不知道在哪个山头修炼。”

视觉场景：

咖啡店角落，电脑开着奇怪网页，旁边有书、耳机、笔记和冷掉的咖啡。朋友叫他“出来玩吗？”，他回：“不了，最近研究点东西。”

代表物：

- 耳机
- 电脑
- 书
- 笔记
- 咖啡
- 奇怪图表

不要画成古装道士、仙侠角色或留胡子的高人。“道长”必须是现代年轻人。

## 7. 人物必须有一点不完美

不要所有角色都是：

- 大眼睛
- 小脸
- 标准俊男美女
- 完美比例
- 精致摆拍

允许加入：

- 黑眼圈
- 乱头发
- 坐姿不好
- 鞋带没系
- 衣服有点皱
- 东西拿太多
- 面无表情
- 翻白眼
- 奇怪姿势
- 表情失控

目标：

> 可爱，但不是幼儿；好看，但不是精修偶像；怪，但不是故意装疯。

## 8. 禁止的视觉方向

禁止：

- 幼儿园 Q 版
- 大头娃娃
- 3D 玩具公仔
- Disney 风
- 传统国潮十二生肖
- 仙侠古风
- 中国传统职业装扮
- 十个职业人物
- 十个精英青年
- 统一西装
- 高级咨询公司人格卡
- 过度赛博朋克
- 过度动漫美少年
- 老派 MBTI 仿制

也不要让每个人只是换衣服，而姿势、脸和气质基本相同。

## 9. 第一轮视觉试制

第一轮不要一次做 20 个。

优先试 3 个人格：

1. **道长**
2. **好吃懒做**
3. **老干部**

每个人先做：

- 男版
- 女版

共 6 个角色。

原因：

- 道长：疏离 / 精神世界怪
- 好吃懒做：松弛 / 生活怪
- 老干部：规矩 / 正经怪

如果这三组放在一起，既明显属于同一个 IP 世界，又明显是三种不同的人，说明画风方向成立。

## 10. 视觉方案评审要求

第一轮不要直接批量生成角色。

先提出至少 3 套视觉方向，每套说明：

- 角色比例
- 线条
- 上色方式
- 脸部风格
- 服装设计
- 背景复杂度
- 人物动作方式
- 是否适合网页结果页
- 是否适合分享海报
- 是否适合后续扩展 20 个角色

选择方向后，再进行正式绘制。

## 11. Flow 的公网翻译原则

Flow / secondary pattern 不新增 Core Character，不扩大角色数量。

用户仍然只拿到一个核心人格 IP；Flow 用副属性、badge、短句或小视觉符号表达。

例如：

```text
伤官生财
→ 天生反骨
→ 副属性：反着反着发现能赚钱
```

```text
伤官配印
→ 天生反骨
→ 副属性：杠人之前先查资料
```

```text
七杀 → 印
→ 狠人
→ 副属性：越挨打越升级
```

不要把每个 Flow 都做成新人格，否则类型数量会失控。

## 12. V1 免费结果页建议

免费结果页优先提供：

- 核心人格 IP 名
- 对应单一性别角色
- 一句毒舌总结
- 4–6 个性格标签
- 朋友眼里的你
- A 面
- 玩脱以后
- 一个隐藏副属性 / Flow 入口
- 可直接截图的分享卡
- 二维码 / URL 回流入口

核心目标不是解释完整命理，而是让用户：

> “怎么这么像我。”

然后愿意分享。

## 13. 轻付费方向

轻付费深度人格报告可以重点解锁：

- 为什么你会是这个人格
- 第二驱动力
- 工作 / 学习模式
- 恋爱 / 关系模式
- 金钱观
- 压力状态
- 容易踩的坑
- 成长建议
- 别人容易误解你的地方

不要把报告写成传统八字论文。

用户付费的核心诉求是：
