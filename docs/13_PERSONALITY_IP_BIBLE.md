# V1 八字抽象人格 IP 基线

状态：Presentation / Product V1 人格基线  
适用范围：结果页、分享卡、人格文案、后续角色 IP 设计  
定位：八字版 SBTI；轻娱乐人格测试 + 轻付费深度人格分析与成长建议

> 核心原则：里面认真算，外面认真发疯。

## 1. 当前锁定范围

本文件当前**只锁定人格本身**，不锁定具体角色形象。

已经锁定：

- 10 个 V1 公网人格名称
- 每个人格的核心性格方向
- 每个人格的正向表达与过度表达方向
- 人格之间需要保持可区分的核心气质

当前**未锁定**：

- 人物长相
- 脸型
- 发型
- 身材比例
- 穿搭
- 姿势
- 动作
- 表情
- 道具
- 背景
- 场景
- 画风
- 上色方式
- 角色比例
- 男版 / 女版的具体造型
- 最终分享卡视觉构图

任何现阶段出现过的角色动作、道具、服装、场景或画风，都只能视为**视觉探索参考**，不得当作正式 Canon。

## 2. 产品定位

V1 不追求把网站做成复杂、严肃、学术化的传统八字平台。

核心用户体验：

```text
出生信息
↓
稳定排盘 / 人格映射
↓
抽象人格 IP
↓
免费结果页
↓
可截图分享
↓
轻付费深度人格报告 / 成长建议
```

免费层首先追求：

- 好玩
- 一眼能懂
- 有一点损
- 有生活感
- 愿意截图分享
- 让用户产生“怎么这么像我”的反应

深度付费层再补充：

- 更完整的人格解释
- 工作 / 学习模式
- 关系模式
- 压力状态
- 容易踩的坑
- 成长建议
- 第二驱动力 / Flow

传统八字术语主要留在后台，不要求普通用户理解。

## 3. 与 Machine Contract 的边界

本文件是**展示层 / 产品层人格基线**，不是新的 deterministic interpretation contract。

`modules/interpretation/PERSONALITY_ARCHETYPE_SPEC.md` 继续负责 machine-layer 输出与版本化规则。

本文件不得反向修改：

- 八字事实
- 十神分数
- 人格维度
- deterministic engine

特别说明：

- 当前 machine taxonomy `personality-map/0.2.0` 仍以十神候选为稳定机器层。
- 本文件中的“建禄 / 月劫”属于产品目标人格骨架表达；正式工程绑定前仍需 approved mapping / traditional host 规则确认。
- 不得仅凭本文件假装当前 production engine 已完成传统格局判定。

## 5. 十大人格核心设定

### 5.1 建禄｜犟种

核心性格：强自我驱动、独立、自尊心强，不喜欢轻易求人，遇事习惯自己扛。

正向表达：
- 独立
- 自驱
- 有主见
- 能自己兜底
- 抗事

过度表达：
- 死犟
- 不会求助
- 明明困难仍硬撑
- 别人越劝越坚持

人格锚点：**“不用，我自己来。”**

### 5.2 月劫 / 劫财｜撒币

核心性格：社交和竞争能量强，仗义、爱参与，容易在人群、朋友、资源交换与竞争中变得活跃。

正向表达：
- 仗义
- 敢争
- 行动力强
- 社交有能量
- 容易把人聚起来

过度表达：
- 钱和资源容易流失
- 人来疯
- 争强好胜
- 参与过度
- 边界感变弱

人格锚点：**“算了算了，我来。”**

### 5.3 食神｜好吃懒做

核心性格：重视舒服、享受、表达、趣味和生活感，不喜欢长期高压和苦哈哈硬卷。

正向表达：
- 松弛
- 会享受生活
- 表达力强
- 有创意
- 好相处
- 能制造轻松感

过度表达：
- 拖延
- 怕累
- 沉迷舒服区
- 重要事情也容易往后放

人格锚点：**“急啥，再玩会儿。”**

### 5.4 伤官｜天生反骨

核心性格：不盲从，喜欢质疑规则、权威与固定流程，倾向自己判断并重构方法。

正向表达：
- 创新
- 独立判断
- 敢表达
- 重构能力强
- 不盲从

过度表达：
- 嘴硬
- 爱顶
- 容易显得难搞
- 有时为了反对而反对

人格锚点：**“凭什么？”**

### 5.5 正财｜抠抠搜搜

核心性格：务实、重价值和投入产出，对浪费与“不值”比较敏感，倾向稳定管理现实资源。

正向表达：
- 务实
- 稳定
- 会过日子
- 资源利用率高
- 生活管理能力强

过度表达：
- 算太细
- 怕浪费
- 容易舍不得
- 对花费和投入反复权衡

人格锚点：**“这真的值吗？”**

### 5.6 偏财｜搞钱圣体

核心性格：对机会、资源、人脉、项目和商业可能性敏感，容易快速发现新的路子。

正向表达：
- 机会敏感
- 商业直觉强
- 路子多
- 会连接资源
- 反应快

过度表达：
- 项目太多
- 追热点
- 容易三分钟热度
- 什么都想尝试

人格锚点：**“等等，这能不能赚钱？”**

### 5.7 正官｜老干部

核心性格：重责任、规则、分寸、秩序和体面，对“合不合适、像不像样”比较敏感。

正向表达：
- 靠谱
- 有责任感
- 有分寸
- 守规则
- 关键事情不乱来

过度表达：
- 太正经
- 容易端着
- 过度规范
- 容易扫兴
- 容易管太多

人格锚点：**“咱们还是正规一点。”**

### 5.8 七杀｜狠人

核心性格：面对困难、竞争、压力和风险时容易进入行动状态，敢扛、敢碰硬。

正向表达：
- 抗压
- 果断
- 敢承担
- 行动力强
- 硬局能顶

过度表达：
- 对自己太狠
- 容易过度用力
- 什么都当成战斗
- 不容易停下来

人格锚点：**“我来。”**

### 5.9 正印｜活菩萨

核心性格：倾向理解、接住、帮助与照顾别人，也有吸收知识、建立理解框架的一面。

正向表达：
- 包容
- 有耐心
- 理解能力强
- 愿意帮助
- 容易给人安全感

过度表达：
- 替别人操心
- 帮太多
- 容易吃亏
- 自己行动变慢
- 边界模糊

人格锚点：**“算了，我帮你吧。”**

### 5.10 偏印｜道长

核心性格：精神世界强，喜欢冷门、非标准、抽象或多数人不关心的内容，思维路径容易偏离大众常规。

正向表达：
- 冷门洞察
- 精神世界丰富
- 非标准思维
- 容易研究别人忽略的东西

过度表达：
- 越想越远
- 疏离
- 容易闭关
- 容易失联
- 脑回路越来越难懂

人格锚点：**“说了你也不感兴趣。”**

## 6. 视觉设计状态：OPEN

目前角色视觉系统尚未定稿。

后续视觉窗口可以自由探索不同方案，只要满足一个原则：

> 视觉必须服务于已经锁定的人格，而不是反过来用某个造型重新定义人格。

后续可以探索但尚未决定的内容包括：

- 写实 / 卡通 / 手绘 / Editorial / 漫画等风格
- 人物比例
- 角色年龄感
- 男女版差异
- 服装
- 发型
- 表情体系
- 动作体系
- 道具
- 场景
- 色彩系统
- 背景
- 分享卡构图
- 是否使用固定代表物

在产品负责人明确批准某一套角色方案前，任何视觉草图、生成图、Prompt、动作或道具都不得写成固定规范。

## 7. 后续设计流程

正确顺序：

```text
人格 Canon 已锁定
↓
多套视觉方向探索
↓
选择一种总体角色语言
↓
先试 2–3 个人格
↓
确认男女版本与角色一致性
↓
再扩展到完整 10 人格 / 20 角色
↓
最后绑定结果页与分享卡
```

视觉探索阶段允许大胆变化，但不得擅自修改本文件第 4、5 节的人格名称与核心性格方向。
