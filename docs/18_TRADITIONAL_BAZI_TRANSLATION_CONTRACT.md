# 18 — Traditional Bazi → Modern Personality Translation Contract

状态：**PRODUCT DOCTRINE / LOCKED 2026-08-22**

## 1. 最高原则

本产品不创造一套新的“八字人格学”。

产品只做两件事：

1. 按明确、可追溯的传统命理规则计算与判断命盘；
2. 把已经得到的传统命理判断翻译成现代年轻人能理解、能传播的人格语言。

一句话：

> **传统命理负责判断，现代产品负责翻译。**

禁止反过来用现代人格标签、行为维度或产品转化目标修改传统命理结论。

## 2. 禁止自造的内容

以下内容不得作为正式命理判断依据：

- 为了产品效果自行设定“52% 十神 + 18% family + 22% dimensions + 8% strength”之类权重；
- 为了让结果更像 MBTI 而创造新的命格判定公式；
- 用 AI / LLM 直接判断格局；
- 用前端随机数或人为调整生成“人格比例”；
- 因为某十神数量多，就直接把对应 Public Personality 定为主人格；
- 为了保证 10 类均衡分布而修改命理判断；
- 把工程化评分包装成传统命理公认结论。

现有 `personality-map/0.2.0` 中属于现代工程假设的 candidate ranking / dimension weighting，只能视为历史实验或过渡实现，不能作为未来专业报告的传统命理 Source of Truth。

## 3. 两条结果轴必须分离

### A. Traditional Pattern / Structure

回答：**“这个命盘在我们所采用的传统体系里，结构是什么？”**

可能输出包括但不限于：

- 正常成格；
- 兼格 / 多结构并见；
- 成格但不纯；
- 破格 / 有救应；
- 从格 / 假从 / 从格不成立；
- 无法稳定归入单一格局；
- 传统流派存在分歧。

### B. Public Personality Translation

回答：**“把上述传统结构翻译成现代人格语言，最接近哪个 Public Personality？”**

例如：

- 伤官结构 → 天生反骨；
- 偏财结构 → 搞钱圣体；
- 七杀结构 → 狠人；
- 正官结构 → 老干部。

这是一层翻译，不是新的命理判定体系。

## 4. 10 Public Personality 的定位

10 个 Public Personality 是 **传统十神 / 格局原型的现代化人格标签**，不是传统格局本身，也不是科学心理分类。

因此：

> `天生反骨` 不等于“只有伤官格的人才能获得”。

系统必须先得到传统结构，再根据明确的翻译规则决定主标签、副标签与说明。

若命盘不成单一格，也不能强行伪造成纯型。

允许公网表达：

- 主导：天生反骨
- 明显副倾向：搞钱圣体
- 辅助：犟种
- 结构混合度：高

但这些标签的来源必须能回溯到传统结构证据。

## 5. 关于“比例 / 百分比”

传统八字并不存在一套跨流派统一、天然等同于“人格百分比”的标准。

因此在找到并锁定有传统依据、可复现的量化规则之前：

- **禁止展示伪精确人格百分比**；
- 不展示“41% 天生反骨 / 26% 搞钱圣体”作为正式命理结论；
- 可展示排序与强弱层级，如：`主导 / 明显 / 辅助 / 弱`；
- 可在专业折叠区展示底层传统事实，例如十神出现、透藏、月令、根气、组合等，但不能把工程权重包装成传统百分比。

如果未来确实要显示百分比，必须先完成：

```text
传统来源 / 规则体系锁定
→ 量化方法有明确依据
→ 规则版本化
→ 专家审查 / 典型命例回测
→ 同盘可复算
→ 再允许公网展示
```

## 6. 传统规则治理

所有决定命盘结构的规则都必须进入 Rule Source of Truth，并标记：

- `TRADITIONAL_CORE`：所选传统体系中的核心规则；
- `SCHOOL_CHOICE`：不同流派有分歧，本产品明确选择其中一种；
- `IMPLEMENTATION_DETAIL`：为了程序实现而存在，但不改变命理语义；
- `EXPERIMENTAL`：研究/实验，禁止进入正式命理结论。

每条正式规则至少记录：

- 规则说明；
- 来源 / 流派；
- 适用条件；
- 冲突规则；
- 不确定性；
- 代码版本。

## 7. 下一阶段必须先做的审计

在继续实现 Personality Mix 之前，先审计现有 Bazi / Interpretation：

1. 四柱 / 节气 / 十神映射；
2. 藏干与月令；
3. 旺衰；
4. 格局取法；
5. 成格 / 败格 / 破格 / 救应；
6. 从格及特殊格局；
7. 合冲刑害与组合；
8. 现有数值权重和阈值；
9. `personality-map/0.2.0` 的现代工程假设。

输出三类清单：

```text
传统有依据，可保留
流派有争议，需要锁定规则
自造工程化判断，需要退出正式命理链路
```

## 8. 正确的最终架构

```text
Birth
↓
Deterministic Bazi Calculation
↓
Traditional Structure Engine
├─ 十神 / 月令 / 透藏 / 根气
├─ 旺衰
├─ 格局候选
├─ 成败 / 破格 / 救应
├─ 从格 / 特殊结构
└─ 组合关系
↓
TraditionalPatternResult + Evidence
↓
Translation Layer
├─ 主 Public Personality
├─ 副 Public Personality / 次级倾向
└─ 现代场景化文案
↓
Character IP / Dossier / Share Card
```

LLM 只能在最后解释与表达，不能重新排盘、重新取格或修改传统结构结果。

## 9. 产品可信度承诺

产品不宣称八字是经过现代科学验证的人格测量工具。

产品应承诺的是：

> **采用明确的一套传统命理规则，计算可复现，判断有依据，争议有说明；现代人格只是对传统结构的语言翻译。**
