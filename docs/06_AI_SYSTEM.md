# 06 — AI System

状态：Draft。

## 1. AI 在本产品中的职责

AI 负责“解释与建议”，不负责凭空完成确定性的八字排盘计算。

推荐链路：

出生信息
→ 确定性八字引擎
→ 结构化命盘 JSON
→ 解释层 / 报告生成层
→ 免费报告 / 完整报告
→ AI 顾问连续问答

## 2. 核心原则

### 计算与解释分离

四柱、十神、大运等核心排盘信息必须来自可靠计算逻辑。

LLM 的任务包括：
- 结构化解释
- 提炼人格模式
- 将传统术语翻译成现代语言
- 结合不同命盘信号形成综合判断
- 给出可执行建议

### 避免“万能套话”

AI 输出必须尽可能引用命盘中的具体结构作为解释依据，而不是只输出任何人都适用的泛化描述。

### 现代行为指导

产品表达优先：
- 倾向
- 可能性
- 行为模式
- 环境适配
- 可执行建议

避免将推断包装成不可改变的绝对命运。

## 3. 报告结构建议

完整报告至少可以分为：

1. 你的核心人格结构
2. 优势与天然能力
3. 容易卡住的模式
4. 情绪与压力反应
5. 人际与亲密关系
6. 工作方式与事业方向
7. 金钱与风险倾向
8. 大运/阶段性背景
9. 近期可执行建议
10. 可继续向 AI 顾问追问的问题

最终章节由产品窗口验证后冻结。

## 4. Free vs Paid

免费报告必须真正有价值，但不能交付完整结论。

建议原则：
- Free：证明系统理解了用户
- Paid Full Report：解释“为什么”、覆盖更多人生主题、给出结构化行动建议

## 5. AI Advisor

顾问每次回答应自动获得必要上下文：
- 当前用户命盘结构
- 已生成报告的核心摘要或相关章节
- 必要的历史会话
- 用户当前问题

不要要求用户反复重新输入出生资料。

## 6. Prompt 版本化

至少保存：
- `report_prompt_version`
- `advisor_system_prompt_version`
- `report_schema_version`
- `model_id`

任何重大 Prompt 变更必须能区分历史版本。

## 7. 输出安全与体验

在涉及医疗、法律、投资等高风险现实决策时，不应把八字推断作为专业建议替代品。

避免：
- 恐吓式灾祸表述
- 必然死亡/疾病等绝对预测
- 让用户因命理结论进行高风险行为
- 故意制造焦虑推动付费
